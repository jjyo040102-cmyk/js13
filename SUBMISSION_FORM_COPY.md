## Title
STEAL THE RAINBOW

## Category
Desktop

## Short description
Steal a colour from one object and give it to another. The last unicorn must return all seven powers to a monochrome world.

## Description
The world has forgotten colour. The last unicorn cannot create it — only steal it.

Take **red** from a fire to extinguish it, then give that red to thorns to burn a path. Borrow **blue** from one object to freeze an enemy into a platform, reclaim **green** from a bridge to grow another, power gates with **yellow**, move heavy stones with **orange**, bend gravity with **indigo**, and connect space with **violet**.

Your horn can carry only **one colour at a time**, so every solution is about moving a power, using it, and deciding when to take it back. Collect all seven rainbow diamonds in each chapter and return them to the rainbow arch.

Ten handcrafted chapters introduce the seven powers one by one before combining them in larger puzzles. Everything is generated at runtime with Canvas 2D and Web Audio: no image files, audio files, libraries, fonts, or network requests are needed to play.

**Built with AI assistance.** ChatGPT assisted with design iteration, implementation, procedural audio, optimization, QA, and documentation. There is no runtime AI service in the game.

## Controls
- **A / D** or **Left / Right** — move
- **W / Space / Up** — jump; hold for a higher jump
- **S / Down** — drop through leaf bridges / descend faster
- **Left click** — take colour from an object / give the held colour
- **Z** — undo the last colour transfer
- **R** — restart chapter
- **H** — show chapter hint
- **Esc** — pause / resume
- **M** — toggle sound
